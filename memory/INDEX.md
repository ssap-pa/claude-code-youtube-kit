# 학습 메모리 목록

규칙 하나 = `rules/<이름>.md` 한 개. 새 영상을 시작하기 전에 이 목록을 읽고, 관련 규칙 파일을 열어 적용한다.

## 대본
- [지어낸 수치·후기 금지](rules/no-invented-facts.md) — 숫자·후기·댓글은 원문이나 실제 화면에서 확인한 값만 쓴다. 과장된 어조·반올림은 괜찮다
- [숫자는 대본에 한글로](rules/number-reading.md) — 횟수·개수(번·개·명·시간·가지)는 고유어(한 번·세 가지), 번호·날짜·%는 한자어로 대본에 한글로 쓴다
- [대본 영어는 대문자](rules/uppercase-english.md) — 대본의 영어 약어·제품명은 대문자(AI·CEO)나 한글 표기로 쓴다

## 화면
- [텍스트 딱지 붙이지 않기](rules/no-label-chips.md) — 화면에 '예시'·'재연'·'광고' 같은 텍스트 딱지(칩)를 붙이지 않는다. 필요한 고지는 업로드 설정·설명란으로
