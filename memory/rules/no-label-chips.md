**규칙.** 화면에 '예시'·'재연'·'광고' 같은 텍스트 딱지(칩)를 붙이지 않는다. 필요한 고지는 업로드 설정·설명란으로

**왜.** 딱지가 화면을 싸 보이게 하고 시청 흐름을 끊는다(한 번 말한 뒤 다른 영상 대본에서도 자동으로 빠지는지 확인한 규칙)

**어떻게 적용.** 화면에 '예시'·'재연'·'광고' 같은 텍스트 딱지(칩)를 붙이지 않는다. 필요한 고지는 업로드 설정·설명란으로
