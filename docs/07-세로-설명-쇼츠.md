# 07. 세로 설명 쇼츠

"왜 ~일까?"를 3D 모형으로 30초~3분에 설명하는 세로(9:16) 영상. 흐름 전체는 `shorts-explainer` 스킬에 있다.

## 바로 해 보기 (예제 40초)

```bash
python tools/new_video.py --shorts my-first-short
```
1. `videos/my-first-short/script.json`의 `voice_id`에 내 목소리 ID를 넣는다(`python tools/voice.py --voices`). 키 없이 해 보려면 3번에서 `--demo`.
2. 순서대로:
```bash
python tools/voice.py videos/my-first-short
python videos/my-first-short/build_v1.py
python tools/make_final.py videos/my-first-short final-v1
python tools/qa.py videos/my-first-short final-v1
```
렌더는 장면 6개를 병렬로 찍어 일반 PC에서 2분 안팎(그래픽 카드가 없으면 더 걸린다).

## 구성 요소

| 무엇 | 파일 |
|---|---|
| 세로 화면(1080x1920)·자막·숫자 카드 모양 | `tools/realkit/vertical.css` |
| 말 자막(단어 시각에 맞춰 2~3단어씩) | `tools/realkit/captions.js` + 빌더의 `V.captions(...)` |
| 3D 장면 도우미(three.js r160, MIT) | `tools/realkit/scene3d.js`, `tools/realkit/vendor/three.min.js` |
| 예제 모형·장면 | `templates/shorts/clips/v1/` (`burj.js`, `a~f.html`) |
| 빌더 | `templates/shorts/build_v1.py` (`RK_FORMAT=vertical`) |
| AI 장면 생성(선택, 요금) | 전체 키트에 있어요(Gemini Omni 영상 연결) — https://ssapable.com/courses/youtube-automation-kit |

## 참고 채널 스타일 따라 하기

Claude에게: "이 채널 쇼츠 상위 영상 두세 편 분석해서 스타일 규칙으로 저장해 줘: <주소>". 컷 간격·자막 위치·대본 뼈대·숫자 비유 방식이 `memory/rules`에 남고, 다음 쇼츠부터 자동 적용된다. 그 채널의 영상·장면·고유 문구는 쓰지 않는다.

## 3D 장면 vs AI 생성 장면 (AI 생성은 전체 키트)

| | 3D 장면(기본) | AI 생성(Gemini Omni 등) |
|---|---|---|
| 비용 | 없음 | 장면마다 요금 |
| 결과 | 매번 같음, 숫자·위치 정확 | 매번 다름, 사실과 다른 모양이 나올 수 있음 |
| 잘 맞는 것 | 구조·흐름·크기 비교·원리 | 실사 인물·현장 분위기 |
| 고치기 | 코드 한 줄(카메라·색·시점) | 다시 생성 |
