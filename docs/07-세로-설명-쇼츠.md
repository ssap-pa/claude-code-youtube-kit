# 07. 세로 설명 쇼츠

"왜 ~일까?"를 3D 모형으로 30초~3분에 설명하는 세로(9:16) 영상. 흐름 전체는 `shorts-explainer` 스킬에 있다. Claude에게 "쇼츠 주제 제안해 줘"라고 하면 최근 24시간 보도와 상시 "왜?" 주제에서 후보 3개를 골라 준다.

## 두 가지 스타일 — 장면을 만들기 전에 고른다

| | 로우폴리 3D (기본) | 실사 스타일 (전체 키트) |
|---|---|---|
| 모습 | three.js 코드로 그린 건축 모형 느낌. 평면 음영, 베이지·회색 위주 색, 따뜻한 오후 빛 | 시선을 잡는 컷(첫 장면·전환·반전)은 AI 실사 영상, 원리 설명 컷은 3D 도식 |
| 비용 | 0원 | AI 컷 하나(9:16 720p 약 10초)에 약 $1 — 정확한 요금은 Google AI Studio 공식 요금 화면 |
| 강점 | 숫자·위치가 정확한 도식, 매번 같은 결과, 코드 한 줄로 수정 | 현장감·인물·분위기, 첫 3초 붙잡기 |
| 확인 | 정지 시안 ✋ | AI 컷 목록·예상 요금 승인 ✋ 뒤에만 생성 |

고른 스타일은 영상 폴더 `SYNOPSIS.md`에 적고.

**실사 스타일은 전체 키트에 있어요**(AI 실사 컷 생성 연결 — https://ssapable.com/courses/youtube-automation-kit). 무료 키트에서도 직접 찍은 실제 영상을 첫 컷으로 깔고 3D로 잇는 방식은 쓸 수 있다(스킬 5절).

## 바로 해 보기

```bash
python tools/new_video.py --shorts my-first-short             # 빈 틀(3D 장면 하나 + 빌더 뼈대)
python tools/new_video.py --shorts --example burj-demo        # 완성 예제(부르즈 할리파 40초)
```
1. **목소리 먼저.** `script.json`의 `voice_id`가 비어 있으면 `voice.py`가 멈추고 고를 목록을 보여 준다. `python tools/voice.py --voices` — 내 목소리(복제)와 ElevenLabs 기본 제공 목소리가 함께 나온다. 키 없이 흐름만 시험하려면 `--demo`(무음, 업로드용 아님).
2. 순서대로:
```bash
python tools/voice.py videos/my-first-short
python videos/my-first-short/build_v1.py
python tools/make_final.py videos/my-first-short final-v1
python tools/qa.py videos/my-first-short final-v1
```
렌더는 장면을 병렬로 찍어 예제 기준 일반 PC에서 2분 안팎(그래픽 카드가 없으면 더 걸린다).

배경음은 처음엔 데모 합성음(시험용)이다. 업로드할 영상은 저작권이 확인된 내 곡을 `assets/bgm/`에 넣고 영상 폴더 `bgm.json`에 적는다.

| 무엇 | 파일 |

| AI 장면 생성(선택, 요금) | 전체 키트에 있어요(Gemini Omni 영상 연결) — https://ssapable.com/courses/youtube-automation-kit |

## 자주 쓰는 설정

- **자막 숫자:** 빌더 위쪽 `SUB = {'팔백이십팔': '828', '사십': '40', '센티미터': 'cm'}`. 낱말 전체가 같을 때만 바뀐다(피사·공사·만든·오면은 그대로). 숫자 뒤 단위는 붙여서 '19층', '40cm'.
- **숫자 세기 카드:** `<span data-count="828" data-ct="num"></span>m`. 천 단위 쉼표가 기본이고, 연도는 `data-year`로 쉼표를 끈다.
  ```html
  <span data-count="1178" data-from="1173" data-year data-ct="five"></span>   <!-- 1173 → 1178 (1,178 아님) -->
  <span data-count="14500" data-sep="none" data-ct="w"></span>t              <!-- 다른 숫자도 쉼표 끄기 -->
  ```
- **3D 꼬리표:** `S.tag(el, [x, y, z])`가 세로 안전 영역(위 220px·아래 380px·좌우 40px) 안에 붙잡고, 말 자막 띠(1100~1260px)를 피해 위·아래로 비킨다. 세로 화면은 좌우가 좁아 카메라 거리 900에서 화면 끝이 ±약 200단위다(`S.viewHalf(거리)`).
- **땅속 단면:** `S.section({ found: { r: 98, h: 30 } })` — 잔디·모래·무른 점토·깊은 모래 지층과 묻힌 기초. 층 색·두께는 `layers`로 바꾼다.

## 참고 채널 스타일 따라 하기

Claude에게: "이 채널 쇼츠 상위 영상 두세 편 분석해서 스타일 규칙으로 저장해 줘: <주소>". 컷 간격·자막 위치·대본 뼈대·숫자 비유 방식이 `memory/rules`에 남고, 다음 쇼츠부터 자동 적용된다. 그 채널의 영상·장면·고유 문구는 쓰지 않는다.

## 3D 장면 vs AI 생성 장면 (AI 생성은 전체 키트)

| | 3D 장면(기본) | AI 생성(Gemini Omni 등) |
|---|---|---|
| 비용 | 없음 | 장면마다 요금 |
| 결과 | 매번 같음, 숫자·위치 정확 | 매번 다름, 사실과 다른 모양이 나올 수 있음 |
| 잘 맞는 것 | 구조·흐름·크기 비교·원리 | 실사 인물·현장 분위기 |
| 고치기 | 코드 한 줄(카메라·색·시점) | 다시 생성 |
