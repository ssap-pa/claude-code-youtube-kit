# 04. 편집과 음성·화면 싱크 검수

## 1. 싱크를 '맞추는' 게 아니라 '어긋날 수 없게' 만든다

편집 도구(`tools/realkit`)는 화면 움직임의 시각을 초로 적지 않는다. 대사 **단어 시각**에서 신호를 만든다.

```python
V = rk.Voice('renders/voice-v1/voices.json', base=HERE)    # voice.py가 만든 단어 시각
cues = {'fb': V.T('v1-s1', '피드백을')}                     # '피드백을'이 들리기 시작하는 순간
```
```html
<div class="card noti" data-anim="drop@fb">…</div>          <!-- 그 순간 알림이 내려온다 -->
```
- 대본을 고쳐 음성을 다시 만들면 신호도 같이 움직인다.
- 신호에 쓴 단어가 대사에서 빠지면 `KeyError`로 바로 멈춘다(조용히 어긋나지 않는다).
- 장면 길이 = 그 장면 음성 + 0.22초(숨), 30fps 프레임 단위. 합본 도구·검수가 같은 계산을 쓴다.

## 2. 장면 만들기

`templates/video/clips/v1/v1.html`과 `build_v1.py`가 작동하는 예제다. 세 층으로 만든다(자세한 디자인 규칙은 `real-ui-design` 스킬).
1. 뒤: 원본 영상을 흐린 배경 — `rk.seq(원본.mp4, 'clips/v1/src/bg', t0=, dur=, size=(960,540), blur=8, bright=.76)`
2. 가운데: 휴대폰·창 안에서 원본이 실제로 재생 — `rk.seq(..., crop=(x,y,w,h), size=(476,984))` + `<img data-seq="src/screen">`
3. 앞: 알림·카드·숫자 — `data-anim="drop@신호"`, `data-count="276" data-ct="신호"`
- 개인 정보 가리기: `rk.seq(..., boxes=[(x, y, w, h)])`(원본 좌표).
- 효과음은 합성(파일 없음): `noti`·`pay`·`tap`·`click`·`pop`·`whoosh`·`tick`·`done` …
- 정지 시안: `python tools/realkit/realkit.py still clips/v1/v1.html 3.5 preview.png`
- 브라우저에서 바로 보기: `v1.html?t=3.5`(정지), `?play=1`(재생).
- 렌더 경고: 28px 미만 글자, 지정 외 글꼴, 대체 글꼴로 그려진 글자, 없는 신호.

## 3. 합본

```bash
python tools/make_final.py videos/<slug> final-v1
```
클립 소리를 클립 영상 길이에 정확히 맞춰 붙인다 — 클립마다 몇 ms씩 생기는 차이가 쌓여 뒤로 갈수록 입이 밀리는 사고를 막는다.

## 4. 검수 — `python tools/qa.py videos/<slug> final-v1`

| 검사 | 잡는 사고 |
|---|---|
| 판 사슬 | 대본을 고쳤는데 음성을 안 다시 만듦 / 음성은 새로 만들었는데 클립을 안 다시 찍음 / 고친 클립이 합본에 안 들어감 |
| 싱크 | 클립 길이 ≠ 음성 길이(신호 어긋남), 장면 음성이 계획 시각보다 밀림(상호상관, 기준 ±60ms), 영상/소리 길이 차이 |
| 발음 | 받아쓰기 ≠ 대본(영어·고유명사·숫자 오독), 소문자 영어 |
| 배경음 | 두 곡이 겹침, 계획한 곡이 안 나옴, 곡이 구간 끝에서 안 멈춤 |
| 화면·소리 | 검은 화면, 5초 넘게 멈춘 화면, 음량(-20~-12 LUFS, peak -1 이하) |
| 재발 | `tools/regressions.json`의 대본·코드·배경음 계획 검사 |
| 직접 확인 | 프레임 시트(`qa/sheet-N.jpg`, 3초 간격)를 보고 `[ ]`를 `[x]`로 |

```bash
python tools/qa.py videos/<slug> final-v1 --gate     # 업로드 가능? 아니면 종료 코드 2
```
- 확인이 끝난 예외(사용자가 승인한 발음 등)는 `qa/ok.json` `{"v2-w3": "사용자 승인 10/25"}`.
- 키트 제작 때 일부러 넣은 사고 네 가지(음성 150ms 밀림, 대본만 고침, 소문자 ai, 배경음 구간 겹침)를 모두 ⚠로 잡는 것을 확인했다.
