# 05. 문제 해결

| 증상 | 원인 → 해결 |
|---|---|
| 세션 시작 때 학습 메모리 얘기가 없음 | 훅 신뢰를 안 했거나 `python`이 PATH에 없음 → Claude Code 새 세션에서 훅 허용, 터미널에서 `python hooks/session_start.py`가 목록을 출력하는지 확인. macOS는 `.claude/settings.json`의 `python`을 `python3`으로. 훅은 셸 없이(`args`) 돌아서 Git Bash 없는 Windows에서도 된다 — 첫 메시지부터 훅 오류로 막히면 Claude Code를 최신으로 업데이트 |
| `pip install`이 `UnicodeDecodeError: 'cp949'`로 멈춤 | Python에 딸려 온 오래된 pip(한국어 Windows) → `python -m pip install -U pip` 뒤 다시 |
| 참고 영상 받기 `Requested format is not available` | 세로 쇼츠는 높이가 1280이라 `height<=720`으로 거르면 받을 게 없다 → `-f "bv*[width<=720]+ba/b[width<=720]"`(너비로 거름). 그래도 안 되면 `python -m pip install -U yt-dlp` |
| `ELEVENLABS_API_KEY가 없습니다` | 환경변수를 넣고 터미널·Claude Code를 새로 열지 않음 → 03 문서 1절 |
| `ElevenLabs HTTP 401` | 키가 틀렸거나 권한(Text to Speech) 없음 |
| `ElevenLabs HTTP 422`·`voice_id` 오류 | `settings.voice.voice_id`가 비었거나 내 계정에 없는 목소리 |
| 렌더 경고 `대체 글꼴로 그려진 글자` | 글꼴을 안 받음 → `python tools/get_fonts.py` |
| `playwright` 오류 / 브라우저 없음 | `python -m playwright install chromium` |
| `KeyError: v1-s2: "단어" 0번째 없음` | 신호에 쓴 단어가 대사에 없음(대본을 고침) → 빌더의 `V.T(…, '단어')`를 지금 대사의 단어로 |
| 검수 `대본 ≠ 음성` | 대본을 고친 뒤 `voice.py`를 안 돌림 |
| 검수 `음성이 클립보다 새것` | 음성을 다시 만든 뒤 클립을 다시 안 찍음 → 빌더를 다시 돌려 판 올림 |
| 검수 `받아쓰기 도구 없음` | 키를 넣거나 `pip install faster-whisper` |
| 검수 음량 ⚠ | 클립 음성이 너무 작거나 큼 — realkit가 -16 LUFS로 맞추므로 보통 배경음 `gain_db`가 크다 |
| 렌더가 느림 | 장면 HTML 묶음마다 병렬로 찍는다(동시 개수 = 남은 메모리 ÷ 1.8GB). 실측: 메모리 넉넉한 PC 40초 오프닝 약 2분, 메모리 8GB PC 세로 쇼츠 1분 46초 장면 하나가 3~4분. 한 HTML이 너무 길면 장면별로 나눈다 |
| 렌더 중 브라우저·x264가 갑자기 죽음(메모리 부족) | 동시에 찍는 장면이 많음 → `RK_JOBS=1`(PowerShell은 `$env:RK_JOBS=1`)로 하나씩 찍는다 |
| 윈도에서 한글 깨짐 | 터미널에서 `set PYTHONIOENCODING=utf-8`(PowerShell은 `$env:PYTHONIOENCODING="utf-8"`) |
