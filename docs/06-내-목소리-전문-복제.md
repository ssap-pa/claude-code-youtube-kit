# 06. 내 목소리로 만들기 — ElevenLabs 전문 복제(PVC)

키트는 아무 목소리로나 돌아간다. 하지만 **채널에 오래 남는 건 내 목소리**다. 기본 목소리는 누구나 쓰니까 다른 채널과 똑같이 들리고, 시청자는 목소리로 채널을 기억한다.

전문 복제(Professional Voice Clone)는 내 목소리를 녹음해 AI를 따로 학습시키는 방식이다. 목소리 모양만 흉내 내는 즉시 복제와 달리 **감정과 억양까지** 살린다. 한 번 만들어 두면 그다음부터는 대본만 쓰면 된다. 마이크 앞에 다시 앉을 일이 없다.

## 내 목소리가 좋은 이유

- **채널 정체성.** 영상 열 편, 백 편이 같은 목소리로 이어진다. 기본 목소리는 남의 채널에서도 들린다.
- **감정·억양.** 오프닝 첫 대사처럼 빠르고 센 톤도 내 말투 그대로 나온다(`script.json`의 `"tone": "hype"`).
- **다른 언어도 내 목소리로.** 같은 복제 목소리로 영어·중국어 같은 외국어 음성도 만들 수 있다(모델 `eleven_multilingual_v2`).
- **고칠 때 녹음이 필요 없다.** 대사 한 줄을 고치면 그 장면만 다시 합성한다. 캐시 덕분에 고친 장면만 크레딧이 든다.
- **본인 목소리만 된다.** 만들 때 화면 문장을 직접 읽어 본인 확인을 하므로, 남이 내 목소리를 복제할 수 없다.

## 준비물

- ElevenLabs **Creator 요금제 이상**. 무료·Starter에는 전문 복제 자리가 없고, Creator·Pro에 1개가 있다. 요금과 행사는 가입 화면에서 확인한다.
- 마이크. 아무 마이크나 되지만 콘덴서 마이크 + 오디오 인터페이스가 좋다. 팝 필터가 있으면 더 좋다.

## 1. 녹음하기

공식 권장 기준이다. 녹음 뒤 `python tools/check_recording.py <파일 또는 폴더>`로 검사하면 기준에 맞는지 바로 알려 준다.

| 항목 | 기준 |
|---|---|
| 형식 | MP3 192kbps 이상(WAV라고 더 좋아지진 않는다) |
| 크기 | 평균 -23 ~ -18 dB RMS, 최고점(true peak) -3 dB 이하 |
| 거리 | 입과 마이크 사이 주먹 두 개 |
| 내용 | 혼자, 말만(노래 X), 한 가지 말투로, 배경음악·잡음 없이 |
| 언어 | 실제로 쓸 언어(한국어 채널이면 한국어로) |

**무엇을 읽나.** 실제 영상과 같은 말투가 제일 좋다.
- 내가 쓴 블로그 글, 예전 영상 대본, 키트로 만든 `script.json` 대사를 읽는다.
- ElevenLabs 녹음 화면(Record yourself)에 있는 예문(이야기체·대화체·광고체)을 읽어도 된다.
- 내레이션 채널이면 내레이션 말투 한 가지로 끝까지 간다. 말투가 섞이면 결과도 섞인다.

**요령.**
- 30분씩 나눠 녹음하고 물을 마신다(한 번에 오래 하면 목이 쉬어 뒤쪽 녹음 질이 떨어진다).
- 실수한 문장은 멈추지 말고 다시 읽는다. 나중에 지우지 않아도 된다.
- 녹음 날마다 마이크·위치·방을 같게 한다.

## 2. 올리고 본인 확인

1. [ElevenLabs](https://try.elevenlabs.io/surgaf77dx55) 로그인 → **Voices** → **Create Voice** → **Professional Voice Clone**.
2. **Upload samples**로 녹음 파일을 올린다(또는 **Record yourself**로 그 자리에서 녹음). 올린 뒤 화면의 분량 표시를 확인한다.
3. 잡음이 있는 파일은 파일 옆 **Audio settings**에서 배경 잡음 제거를 켠다.
4. **본인 확인:** 화면에 나오는 문장을 소리 내 읽는다.
   - 녹음 때와 같은 마이크, 같은 말투로 읽는다.
   - 한 줄씩 한 번만 읽고 Stop을 누른다.
   - 여러 번 실패하면 24시간 뒤에 다시 하거나 support@elevenlabs.io에 문의한다.
5. **학습 기다리기:** 몇 시간에서 하루 정도 걸린다(공식 안내 3~24시간). 끝나면 앱 알림과 메일이 온다.

## 3. 키트에 연결

```bash
python tools/voice.py --voices          # 내 계정의 목소리와 voice_id 목록(전문 복제는 [professional])
```
나온 `voice_id`를 영상 폴더 `script.json`에 넣는다:
```json
"voice": {"voice_id": "여기에", "model_id": "eleven_multilingual_v2",
          "voice_settings": {"stability": 0.5, "similarity_boost": 0.8, "style": 0, "use_speaker_boost": true, "speed": 1}}
```
새 작업을 시작할 때 `videos/demo/script.json`을 복사해 쓰면 처음부터 내 목소리다.

시험: `python tools/voice.py videos/<slug> v1` → `renders/voice-v1/` 음성을 들어 본다.
- 너무 단조로우면 `stability`를 0.4로 낮춘다.
- 너무 들쑥날쑥하면 0.6으로 올린다.
- 바꾼 값이 마음에 들면 Claude에게 "이 설정 앞으로 계속 써"라고 말한다. 그 말이 학습 메모리에 규칙으로 남는다.

## 자주 묻는 것

- **즉시 복제로는 안 되나?** 된다. 1분 안팎 녹음으로 몇 초 만에 만들어지고 Starter 요금제부터 쓸 수 있다. 다만 감정·억양 재현이 전문 복제보다 약하다. 먼저 즉시 복제로 키트를 시험하고, 채널을 계속할 생각이 들면 전문 복제로 바꿔도 된다.
- **복제한 목소리 파일을 받을 수 있나?** 파일로 내려받을 수는 없다. API 키로 어디서든 불러 쓸 수 있다(키트가 쓰는 방식).
- **발음이 틀리는 단어는?** 목소리 문제가 아니라 표기 문제인 경우가 많다. 대본은 그대로 두고 `settings.pron`에 소리 나는 대로 등록한다(docs/03).
