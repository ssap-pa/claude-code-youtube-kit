# 01. 설치

| 프로그램 | Windows | macOS |
|---|---|---|
| Claude Code | Claude 데스크톱 앱의 Code 탭 또는 터미널 `claude` | 같음 |
| Python 3.10+ | [python.org](https://www.python.org/downloads/) 설치 때 "Add python.exe to PATH" 체크 | `brew install python` |
| ffmpeg | `winget install Gyan.FFmpeg` (설치 뒤 터미널을 새로 연다) | `brew install ffmpeg` |

키트 폴더에서:
```bash
pip install -r requirements.txt
python -m playwright install chromium
python tools/get_fonts.py
python tests/test_free.py
```
- `playwright`는 장면 HTML을 프레임마다 찍는 브라우저다(편집 도구가 쓴다).
- `get_fonts.py`는 기본 글꼴 하다 산스를 공식 배포처에서 `tools/realkit/fonts/`로 받는다.
- 테스트가 모두 `ok`면 끝. macOS에서 `python`이 없으면 `python3`으로 쓰고, `.claude/settings.json`의 훅 명령도 `python3`으로 고친다.

Claude Code로 폴더를 처음 열 때 훅을 신뢰할지 묻는다. 허용해야 학습 구조가 작동한다.
확인 방법: 새 세션에서 "세션 시작 때 받은 학습 메모리 목록 제목만 말해 줘" → `memory/INDEX.md`의 제목들이 나와야 한다.

데모 영상(키 없이):
```bash
python tools/new_video.py demo-hello
python tools/voice.py videos/demo-hello --demo
python videos/demo-hello/build_v1.py
python tools/make_final.py videos/demo-hello final-v1
python tools/qa.py videos/demo-hello final-v1
```
